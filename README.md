# Vible Online Teaching Platform

A Next Generation Online Teaching Platform built with **Nuxt 4** and **Vue 3**.

## 📋 Overview

Vible is an online teaching platform designed to facilitate remote education, featuring interactive learning tools, real-time collaboration, and a modern user interface.

## 🏗️ Tech Stack

- **Framework**: Nuxt 4 (Vue 3)
- **Language**: TypeScript & Javascript
- **Styling**: Tailwindcss (CSS)
- **Package Manager**: npm
- **Code Quality**: ESLint, Prettier

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run preview

# Postinstall
npm run prepare
npm run postinstall
```
